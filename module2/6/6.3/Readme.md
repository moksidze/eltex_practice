Задание №6.3

Задание

Доработать решение задачи 2.3 (калькулятор) так, чтобы
функции загружались из динамических библиотек. В одной библиотеке
находится одна функция. При запуске программы считывается каталог с
библиотеками и загружаются найденные функции.

Выполненная работа

В ходе выполнения задания была выполнена переработка программы калькулятора.

1. Созданы динамические библиотеки

Каждая арифметическая операция вынесена в отдельную динамическую библиотеку.

Созданы библиотеки:

* `add.so` — сложение;
* `sub.so` — вычитание;
* `mul.so` — умножение;
* `div.so` — деление.

Для каждой библиотеки создан отдельный исходный файл с реализацией соответствующей функции.

2. В библиотеки вынесены

В динамические библиотеки вынесены функции:

* `AdditionValues()` — сложение чисел;
* `SubtractValues()` — вычитание чисел;
* `MultiplyValues()` — умножение чисел;
* `DivideValues()` — деление чисел.

Каждая библиотека содержит реализацию только одной арифметической операции.

3. Основная программа

Файл `main.c` содержит пользовательское меню, ввод двух чисел и выбор необходимой операции.

При запуске программы загружаются найденные динамические библиотеки, после чего пользователю становится доступен список арифметических операций.
После выбора пункта меню вызывается соответствующая функция из загруженной библиотеки.

4. Организация программы

Программа построена по модульному принципу.

Каждая арифметическая операция реализована независимо от остальных, что позволяет добавлять новые функции без изменения структуры программы.
Общие объявления функций находятся в заголовочном файле `calc.h`.

5. Сборка проекта

Сборка проекта выполняется с помощью `Makefile`, который:

* компилирует исходные файлы;
* создает динамические библиотеки;
* собирает основную программу калькулятора.

Для запуска программы также используется файл `script.sh`.

6. Доработка задания

Исправлен вывод меню в main.c, программа больше не завершается после выполнения одной арифметической операции и повторно отображает меню. 
Добавил функции для динамической загрузки библиотек dlopen(), dlsym() и dlclose().
Также изменил функции библиотек и обновил Makefile для сборки каждой динамической библиотеки отдельной целью.

После запуска программы и выполнения арифметической операции в каталоге libs удалил add.so, операция пропала из меню, 
после выполнения еще одной операции добавил add.so с помощью команды make add во втором терминале и операция снова появилась в меню.

Результат

В результате выполнения задания арифметические операции были успешно вынесены в отдельные динамические библиотеки.
Основная программа использует загруженные библиотеки для выполнения вычислений, что делает калькулятор более модульным, расширяемым и удобным для сопровождения.
