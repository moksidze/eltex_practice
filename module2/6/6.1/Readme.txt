Задание №6.1

Задание

Доработать решение задачи 4.1 (список контактов) так, чтобы
структуры и функции по работе с двухсвязным упорядоченным списком
находились в статической библиотеке.

Выполненная работа

В ходе выполнения задания была выполнена переработка программы телефонной книги.

1. Создана статическая библиотека

В отдельный модуль были вынесены все структуры и функции, отвечающие за работу с двухсвязным упорядоченным списком контактов.

На их основе была собрана статическая библиотека `libbook.a`.

2. В библиотеку вынесены

В статическую библиотеку вынесены:

* структура `contact`;
* функция `AddContact()` — добавление нового контакта;
* функция `EditContact()` — редактирование существующего контакта;
* функция `DeleteContact()` — удаление контакта;
* функция `WatchContact()` — получение списка контактов.

Все операции над двухсвязным списком выполняются внутри статической библиотеки.

3. Основная программа

Файл `main.c` содержит пользовательское меню и обработку ввода данных.

При выборе пунктов меню вызываются функции из статической библиотеки для выполнения операций добавления, редактирования, удаления и просмотра контактов.

4. Организация списка

Контакты хранятся в двухсвязном упорядоченном списке.

При добавлении нового элемента поддерживается сортировка:

* сначала по фамилии;
* при совпадении фамилии — по имени.

5. Тестирование

Для проверки корректности работы библиотеки создан файл `test.c`, в котором проверяются:

* добавление контактов;
* сохранение сортировки;
* редактирование данных;
* удаление контактов;
* попытка удаления несуществующего контакта.

Для автоматической проверки используются функции `assert()`.

6. Сборка проекта

Сборка проекта выполняется с помощью `Makefile`, который:

* компилирует исходные файлы;
* создает статическую библиотеку `libbook.a`;
* собирает основную программу;
* собирает тестовую программу.

Результат

В результате выполнения задания структура данных и функции работы с двухсвязным упорядоченным списком были успешно перенесены в статическую библиотеку.
Основная программа использует библиотеку для выполнения всех операций над телефонной книгой, что делает проект более модульным, удобным для сопровождения и повторного использования.
