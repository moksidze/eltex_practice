Задание №4.3

Задание

Доработать решение задачи 2.1 (список контактов) так, чтобы
для хранения данных использовалось бинарное дерево. Добавить
периодическую балансировку дерева.

Выполненная работа

В ходе выполнения задания была выполнена переработка программы телефонной книги.

1. Реализовано бинарное дерево поиска

Для хранения контактов вместо списка используется бинарное дерево поиска.

Каждый контакт представляет собой узел дерева, содержащий информацию о пользователе и ссылки на левое и правое поддеревья.

2. Организация хранения данных

Добавление новых контактов выполняется в соответствии с фамилией и именем пользователя.

Поиск, редактирование и удаление контактов осуществляются путем обхода бинарного дерева.

Для просмотра телефонной книги используется симметричный обход дерева, благодаря чему контакты выводятся в отсортированном порядке.

3. Периодическая балансировка дерева

Для повышения эффективности поиска реализована автоматическая балансировка дерева.

После каждых десяти операций добавления или удаления все элементы дерева последовательно записываются в массив, после чего на его основе строится новое сбалансированное бинарное дерево.

4. Основная программа

Файл `main.c` содержит пользовательское меню и обработку ввода данных.

Пользователю доступны следующие операции:

* добавление контакта;
* редактирование контакта;
* удаление контакта;
* просмотр списка контактов.

Все операции выполняются с использованием бинарного дерева.

5. Тестирование

Для проверки корректности работы программы создан файл `test.c`, в котором проверяются:

* добавление контактов;
* создание бинарного дерева;
* редактирование данных;
* удаление контактов;
* проверка отсутствия удаленного контакта;
* корректный вывод контактов в отсортированном порядке;
* автоматическая балансировка дерева после выполнения необходимого количества операций.

6. Сборка проекта

Сборка проекта выполняется с помощью `Makefile`, который:

* компилирует исходные файлы программы;
* собирает основную программу;
* собирает тестовую программу.

Результат

В результате выполнения задания хранение контактов было успешно реализовано с использованием бинарного дерева поиска.
Добавлена автоматическая периодическая балансировка дерева, благодаря чему сохраняется эффективность операций поиска, добавления и удаления контактов при увеличении количества записей.
